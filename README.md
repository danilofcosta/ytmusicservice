# ytmusicservice

🎧 **ytmusicservice** é um pacote Flutter/Dart para acessar e extrair informações do YouTube Music e vídeos do YouTube. Ele é baseado em [`dart_ytmusic_api`](https://pub.dev/packages/dart_ytmusic_api) e utiliza a poderosa biblioteca [`youtube_explode_dart`](https://pub.dev/packages/youtube_explode_dart).

Ideal para apps de música, players personalizados, bots ou qualquer ferramenta que precise interagir com conteúdo público do YouTube.

---

## 🚀 Funcionalidades

- 🔎 Pesquisar músicas, vídeos, álbuns e artistas no YouTube.
- 🎵 Obter metadados de músicas e vídeos (título, artista, duração, etc.).
- 📁 Navegar e listar playlists e álbuns.
- 📺 Extrair informações detalhadas de vídeos.
- 📡 Acesso via URLs ou IDs diretos do YouTube.
